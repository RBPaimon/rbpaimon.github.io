RBPaimon Agents Library

A tool-using AI agent system for Roblox

Players ask questions in plain language. The library decides which tool answers them, runs that tool on the server, and returns a human-readable reply — securely and cost-efficiently. This page explains how it works conceptually; it does not publish the plugin's source code.

What it is

The plugin is a reusable, server-authoritative agent system shared across RBPaimon places. Other packages register categories and tools into a shared registry. When a player asks something, the library narrows down to the right tool, runs it, and writes the final answer.

How a request flows

1

Category selection

The client sends the question as an intent — it never computes an answer. The server shows the model every category and asks it to pick the most relevant one.

2

Tool selection

The server reveals only that category's tools and asks the model to choose a single tool and the arguments it needs. Sending tools in stages keeps token spend low.

3

Execution & answer

The server runs the chosen tool, feeds the result back to the model, and the model writes the final reply. Usage is totalled across all three calls and charged to the player.

Built secure by default

  • Read-only client. The chat GUI only observes server state and sends intents. It never spends tokens, executes tools, or sees the API key.
  • Encrypted API key. The OpenRouter key is stored encrypted at rest and decrypted server-side only. The decryption passphrase is provisioned at runtime and never committed.
  • Server-validated models. Players pick a model from a GUI dropdown backed by a server allowlist, so a client can never request an unlisted model.

Tokens & sessions

A token economy meters AI usage; other packages can grant tokens, and each request deducts what it costs (creators use the AI for free). Chat history lives in server memory only — it is created fresh on join and discarded on leave, never written to a datastore.
